## 2. Inside the AppImage

### System libraries

The AppImage bundles GTK 4, libadwaita, GLib, Pango, Cairo, HarfBuzz, gdk-pixbuf, librsvg,
the Adwaita symbolic icons and their dependencies, taken unmodified from Ubuntu 24.04. Most
are under the GNU LGPL 2.1 or later; the Adwaita icons are under LGPL 3 or CC BY-SA 3.0.

- The exact packages and versions are listed in `usr/share/doc/vinci/bundled-packages.txt`
  inside the AppImage, with each package's copyright and license file in
  `usr/share/doc/vinci/packages/`. The same list is attached to every release.
- Their complete source code, at those exact versions, is attached to every
  [GitHub release](https://github.com/dionatansimioni/vinci/releases) as
  `Vinci-<version>-x86_64.AppImage.sources.tar`, and is also available from Ubuntu
  (`apt-get source <package>=<version>`).
- The libraries are dynamically linked and unmodified. You can replace them: extract the
  AppImage with `--appimage-extract`, swap the `.so` files in `squashfs-root/usr/lib` and run
  `squashfs-root/AppRun`.

## 3. Used, not included

Vinci installs or runs these on your computer, from their official sources, at the moment
they are needed. It does not redistribute them.

| Software | License | How Vinci gets it |
|---|---|---|
| [distrobox](https://github.com/89luca89/distrobox) | GPL-3.0 | Uses yours if compatible; otherwise downloads the pinned release from its GitHub repository into `~/.local/share/vinci/distrobox` |
| [Podman](https://podman.io) | Apache-2.0 | Installed with your distribution's package manager, after you confirm |
| [Ubuntu 24.04 container image](https://hub.docker.com/_/ubuntu) | Various free licenses | Pulled from Docker Hub (or the public Amazon ECR mirror) |
| [FFmpeg](https://ffmpeg.org) and the other container packages | LGPL/GPL and others | Installed inside the container from Ubuntu's repositories |
| [ROCm](https://rocm.docs.amd.com) (AMD) | Various, mostly MIT/Apache | Installed inside the container from AMD's repository |
| [Intel compute runtime](https://github.com/intel/compute-runtime) (Intel) | MIT | Installed inside the container from the Ubuntu/Intel PPA |
| NVIDIA driver | NVIDIA license | Your system's own driver, shared with the container by distrobox |
